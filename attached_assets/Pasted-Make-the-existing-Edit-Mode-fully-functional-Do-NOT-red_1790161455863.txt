Make the existing Edit Mode fully functional. Do NOT redesign the app, reset the database, delete existing user content, or change the current visual style.

CURRENT PROBLEM:
The Edit Mode button exists, but it does not actually let me manually edit or delete existing content. For example, I need to delete old Contacts and rename existing Contacts, but there are no functional editing controls.

GOAL:
When Edit Mode is ON, I must be able to manually CREATE, EDIT and DELETE content throughout the phone, with all changes saved persistently.

CONTACTS — PRIORITY TEST

When Edit Mode is ON and I open Contacts:

Each existing contact must have:

* Edit
* Delete

Also add:

* New Contact

EDIT CONTACT:
Tapping Edit should open the existing contact in an editable form.

Allow editing:

* Display Name
* First Name
* Last Name
* Nickname
* Relationship
* Notes
* Favorite
* Contact Photo

Save must UPDATE the existing record, not create a duplicate.

Example:
Antonella → Edit → Display Name: Nela → Save

The existing Antonella contact should become Nela.

DELETE CONTACT:
Tapping Delete must show:

“Delete this contact?”

Cancel | Delete

After confirmation:

* permanently delete that contact from the Contacts database
* immediately remove it from the visible list
* keep it deleted after refresh
* keep it deleted after closing and reopening the PWA

Deleting a Contact must NOT automatically delete historical Messages, Calls, Gallery items, Diary entries or other records.

NEW CONTACT:

* New Contact must open a blank Contact form and permanently save the new Contact.
